# 更新记录

按北京时间（UTC+8）周一至周日汇总，最新一周置顶，当周内容随开发持续补充。记录 GTOCore 及 GTOLib 的功能、内容、配方、机制、性能与兼容性变化。

## 2026-10-26—2026-11-01

**新增：**

- 挑战规则：不上天挑战。开启后禁止乘坐火箭和打开星图，并允许重力规整器为机器主机提供对应重力条件。
- 官网联动：增加游戏内官网登录和 `/bug` 反馈流程，接入官网联网功能同意页；反馈可附带经过 IP 打码的日志和近期崩溃报告，服务端上传可由服主关闭。
- 搜索与通知：合成材料支持拼音搜索，合成完成通知增加耗时和跟踪状态。

**修改与移除：**

- 抽屉存储器改用超级箱/缸作为存储介质：主机槽和输入总线均放超级箱/缸，支持木质、青春版、量子系列以及普通、1×2、2×2 布局。
- 重新计算抽屉存储器种类数和单种容量；Functional Storage 抽屉与存储升级不再提供收益，移除对应配方。
- AE 存储、存储访问仓、ME 磁盘箱子和多方块 ME 存储改为增量维护已用数量，减少周期性和保存时的全表求和。
- 大整数存储数量改用 126 位双 long 表示，减少 BigInteger 创建；调整大数量比较和显示。
- 游戏内打开官网加入来源标记，完善物品攻略与反馈交互；更新 GTM、新生魔艺等依赖。

**修复：**

- 修复 AE 库存集合接口变化导致 EMI 配方界面注入失败。
- 修复新生魔艺方块挖掘工具标签。
- 完善官网同意状态和错误反馈、日志截取与上传处理。
