# 世界规则只读约定

GTORules 的世界快照只在新建 `PrimaryLevelData` 时确定，并随第一次 `level.dat` 保存写入。创建旧世界的副本也属于新世界，使用本次创建时已加载的规则。

`WorldRulesData` 保存解析后的只读快照和原始规则标签。后续读取不得根据当前配置替换规则；复制 `LevelSettings`、修改原版难度、游戏模式、数据配置或 Forge lifecycle 时，复用同一份规则数据。

Minecraft 会在正常保存时重建整个 `level.dat`，因此仍须原样携带创建时或读取到的规则标签。这是保留原有数据，不是重新确定规则：禁止重新编码旧快照、补充缺失标签、格式升级回写，或从 `common_data` 覆盖世界元数据。旧版难度标签和不可解码的原始标签也原样保留。

已有世界可从 `common_data`、`level.dat_old` 或历史 `common_data` 备份只读识别规则，选档摘要只在内存中展示读取结果。禁止加载时保存规则、选档时修复文件、以当前规则重置旧世界，或提供确认后改写规则的入口。完全没有可读记录的世界不能自动分配当前规则。

全局 `config/gtocore-rules.txt` 是下次启动的配置；为加入已有世界而同步本地配置不改变该世界的规则。世界规则和本地启动配置应分别处理。
